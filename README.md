# Manga PT-BR Sources

Repositório pessoal de fontes PT-BR para Synthetiq Books e Tachimanga.

## Synthetiq Books

Adiciona este repositório na app:

`https://github.com/IceyEternal/synthetiq-mangafire-ptbr`

Fontes incluídas:

- MangaFire PT-BR — principal
- MangaDex PT-BR — backup
- Taiyō PT-BR — segundo backup

## Tachimanga

Adiciona este URL como repositório de extensões:

`https://raw.githubusercontent.com/IceyEternal/synthetiq-mangafire-ptbr/main/tachimanga/index.min.json`

Extensões incluídas:

- MangaFire PT-BR
- MangaDex PT-BR
- Taiyō PT-BR
- Niadd PT-BR
- NoxManga PT-BR

A GitHub Action verifica alterações na Keiyoushi de 6 em 6 horas e recompila automaticamente as cinco extensões quando o upstream muda.
